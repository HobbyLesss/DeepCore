# Deep Core — Windows build v0.4

[Download DeepCore-Windows.zip](https://github.com/HobbyLesss/DeepCore/raw/refs/heads/main/DeepCore-Windows.zip)

Extract the entire ZIP, open the DeepCore folder, and run DeepCore.exe.

## Controls

- V: switch first-person / third-person (saved with your expedition)
- WASD: move; mouse: look; Space: jump; Shift: sprint
- Hold left mouse: mine
- Tab: inventory; Escape: pause
- E: sell; U: upgrade pickaxe; B: expand backpack (near the terminal)
- R: return to surface; F5: save

Includes mesh terrain, an articulated miner, impact-based mining, equipment upgrades, expedition goals, and persistent excavations.

Linux gameplay tests and offscreen rendering were verified. Windows runtime remains untested.
